# DS App — Feature Documentation Index

This document lists all features in the application, their descriptions, and links to their user manuals. Features marked **Pending** do not yet have a user manual.

---

## Features with User Manuals

| Feature | Description | Manual |
|---|---|---|
| **Bench** | Manages moving team members off active projects into an internal bench allocation and back. Supervisors set allocation percentages, functional areas, and end bench periods when team members are reassigned. | [user-manual-bench.md](user-manual-bench.md) |
| **Dynamic Reports** | Enables authorized users to create custom SQL-based reports with configurable parameters, access controls, and export capabilities via a three-step wizard. | [user-manual-dynamic-reports-creation.md](user-manual-dynamic-reports-creation.md) |
| **Endorsements** | Records candidate placements on client projects with compensation bonuses, routed through an approval workflow with country-specific bonus configurations. | [user-manual-endorsements.md](user-manual-endorsements.md) |
| **Hiring** | Bridges approved endorsements to onboarding by creating team member profiles, project assignments, and projected vacation records through draft and execution stages. | [user-manual-hiring.md](user-manual-hiring.md) |
| **Holiday Swaps** | Allows employees to work a public holiday in exchange for a personal day off on a different date, with supervisor approval affecting time-off planning calendars. | [user-manual-holiday-swaps.md](user-manual-holiday-swaps.md) |
| **Maintenance** | Administrative management of all system reference catalogs: employees, supervisors, clients, projects, time-off rules, holidays, roles, and bonus configurations. | [user-manual-maintenance.md](user-manual-maintenance.md) |
| **My Team** | Gives supervisors a consolidated read-only view of direct and indirect reports with access to full profiles, Workday data, and time-off usage summaries. | [user-manual-my-team.md](user-manual-my-team.md) |
| **Project Assignments** | Manages team member allocations to client projects, tracking billing rates, allocation percentages, and engagement duration with full assignment history. | [user-manual-project-assignments.md](user-manual-project-assignments.md) |
| **Reports** | Centralized hub for running pre-configured and custom dynamic reports with filtering, exporting, and parameterized query support. | [user-manual-reports.md](user-manual-reports.md) |
| **Supervisor Time Off** | Enables supervisors to create, edit, and approve time-off requests on behalf of team members with country-specific rules and balance tracking. | [user-manual-supervisor-timeoff.md](user-manual-supervisor-timeoff.md) |
| **Time Off** | Allows employees to request absences (vacation, sick leave, personal days) with automatic balance validation, holiday awareness, and country-specific rules. | [user-manual-timeoff.md](user-manual-timeoff.md) |
| **Standalone Tasks** | Direct, one-off work items assigned to a specific team member. Admins create and manage tasks; assignees mark them complete or dismiss them. Supports optional recurrence via templates. | [Admin & Combined Reference](user-manual-standalone-tasks.md) · [My Tasks (Employee)](user-manual-my-tasks.md) |
| **Workflow Tasks (DTOS)** | Configurable workflow engine for defining multi-step task processes, launching instances, tracking execution, SLA management, escalation rules, and immutable audit trails. | [user-manual-workflow-tasks.md](user-manual-workflow-tasks.md) |
| **Top Performers** | Nomination and voting cycle management for recognizing high-performing team members. Admins manage cycles and anonymization; employees nominate and vote. | [User Manual](user-manual-top-performers.md) · [Admin Manual](user-manual-top-performers-admin.md) |
