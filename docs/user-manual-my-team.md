# My Team — User Manual

> **Version 1.0 · March 2026**
> This manual covers the My Team module: how to view your direct and indirect reports, understand their profiles, and review their time-off usage.

---

## What is My Team?

My Team is a read-only module that gives supervisors a consolidated view of everyone who reports to them — both directly and indirectly. From the list you can see high-level information at a glance, and from each member's profile page you can see full personal, work, location, supervision, and time-off details.

---

## Part 1 — The My Team List

### Where to find it

Navigate to **My Team** from the main menu. This is the main view showing all team members you supervise.

### 1.1 Reading the list

The list shows one row per team member with the following columns:

| Column | Description |
|---|---|
| **WDID** | The member's Workday ID |
| **Full Name** | Legal full name, with nickname shown below if available |
| **Role** | The member's primary role |
| **Country** | The country the member is based in |
| **Report Type** | Whether this is a **Direct** or **Indirect** report |
| **Time Off (year)** | Total time-off days taken in the current calendar year |

Columns can be sorted, resized, and reordered. Use the column visibility control to hide columns you do not need.

### 1.2 Searching

Use the search bar at the top of the list to filter by name, role, country, or any other visible text. The filter applies in real time.

### 1.3 Opening a profile

Click any row to open that team member's profile page (see Part 2).

### 1.4 Report Type badge

The **Report Type** column shows a colored badge:

| Badge | Meaning |
|---|---|
| **Direct** | The person reports directly to you |
| **Indirect** | The person reports to one of your direct reports |

### 1.5 Empty state

If the list is empty, you have no direct or indirect reports currently assigned to you in the system. Contact your administrator if you believe this is incorrect.

## Part 2 — Team Member Profile

### Where to find it

Click any row in the My Team list to open that member's profile page.

### 2.1 Page header

The header displays the member's full name and, if available, their nickname (shown in quotation marks) and Workday ID. Use the back arrow button to return to the My Team list.

### 2.2 Personal Information

| Field | Description |
|---|---|
| **Full Name** | The member's legal first and last name |
| **Known As** | Nickname or preferred name, if configured |
| **Workday ID** | The member's Workday system identifier |

### 2.3 Work Information

| Field | Description |
|---|---|
| **Seniority** | The member's seniority level |
| **Primary Role** | The member's main job role or title |

### 2.4 Location

| Field | Description |
|---|---|
| **Country** | Country where the member is based, with ISO code |

### 2.5 Supervision Details

| Field | Description |
|---|---|
| **Report Type** | Direct or Indirect (see Section 1.4) |
| **Assignment Start Date** | When the supervision relationship began |
| **Assignment End Date** | When the supervision relationship is scheduled to end (shown only if applicable) |
| **Team Member End Date** | If the member has a termination date on record, it is shown here highlighted in red |

### 2.6 Workday Information

This section shows data pulled from Workday. It is only shown when the member has a Workday ID linked. If no Workday ID is linked, the section displays a notice instead.

| Field | Description |
|---|---|
| **Hire Date** | Date the member was hired |
| **Work Style** | e.g., Remote, Hybrid, On-site |
| **Gender** | Gender as recorded in Workday |
| **Birth Date** | Date of birth |
| **Parenthood** | Whether the member has indicated parenthood status |
| **Billing Status** | Current billing status |
| **Cost Center** | The cost center(s) the member belongs to |
| **Direct Manager (Workday)** | The member's direct manager as recorded in Workday (may differ from this system) |
| **Corporate Email** | Company email address |
| **Personal Email** | Personal email address on file |
| **Cellphone** | Mobile phone number |
| **Home Phone** | Home phone number |
| **Vacation Days** | Available vacation day balance |
| **Personal Days** | Available personal day balance |

### 2.7 Time Off Summary

The **Time Off Summary** section shows a breakdown of the team member's time-off usage for the current calendar year.

| Element | Description |
|---|---|
| **Total Time Off** | The grand total of days taken across all categories this year |
| **Category breakdown** | A list of each time-off category (e.g., Vacation, Sick) with the days used and a proportional progress bar |

If no time off has been recorded for the year, the section shows "No time off recorded this year."

> The time-off summary is read-only. To manage or approve time-off requests, use the **Time Off** module.

## Part 3 — Frequently Asked Questions

**Q: My Team list is empty. Why?**
A: You currently have no direct or indirect reports assigned in the system. If you believe this is incorrect, contact your administrator to verify your supervisor assignments.

---

**Q: What is the difference between a Direct and an Indirect report?**
A: A **Direct** report is someone who reports to you personally. An **Indirect** report is someone who reports to one of your direct reports — they are in your extended team but not immediately under you.

---

**Q: A team member's Workday Information section shows "No Workday ID linked." What does this mean?**
A: The member's profile in this system has not been linked to a Workday record. Workday-sourced fields such as hire date, work style, and contact details will not be available until the link is established. Contact your administrator.

---

**Q: The Direct Manager shown in Workday Information is different from me. Is that a problem?**
A: Not necessarily. The **Direct Manager (Workday)** field reflects the hierarchy in Workday, which may differ from the supervision assignments in this system. If you believe there is an error, contact your HR representative.

---

**Q: The Time Off Summary shows 0 days but I know this person has taken time off.**
A: The summary only includes time-off requests that have been recorded and approved within this system for the current calendar year. Time off recorded in another system will not appear here.

---

**Q: A team member has a red "Team Member End Date" on their profile. What does that mean?**
A: It means the member has a scheduled termination or end date on record. This is informational only.

## Summary Cheat Sheet

| I want to... | Where to go | Notes |
|---|---|---|
| View all my reports | My Team (main list) | Shows both direct and indirect reports |
| Search for a specific person | My Team → search bar | Filters by name, role, country, and other visible columns |
| See how much time off someone has taken | My Team list (Time Off column) or Profile → Time Off Summary | List shows the yearly total; profile shows a category breakdown |
| View a team member's full profile | Click any row in the My Team list | Opens the profile page |
| Check a member's Workday details | Profile page → Workday Information section | Only available if the member has a linked Workday ID |
| Approve or manage time-off requests | Time Off module | My Team is read-only |
